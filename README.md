📝 Note App

📌 About the Project

Note App is a simple and user-friendly note-taking application developed using HTML, CSS, jQuery, and jQuery Mobile. It features a modern dark blue and black theme and allows users to easily create, view, search, and delete notes. The application uses browser LocalStorage to save notes, ensuring that they remain available even after refreshing the page.

✨ Features

➕ Add new notes

👀 View saved notes

🔍 Search notes easily

🗑️ Delete notes

💾 Store notes using LocalStorage

🎨 Dark blue and black themed interface

📱 Mobile-friendly design

🛠️ Technologies Used

HTML5
CSS3
JavaScript
jQuery
jQuery Mobile
LocalStorage

⚙️ How to Run

Clone or download this repository.

Open the project folder.

Open index.html in your browser.

Start creating and managing your notes!
